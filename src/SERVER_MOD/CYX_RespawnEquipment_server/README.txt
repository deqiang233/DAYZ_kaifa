===========================================
CYX 复活装备恢复系统 v1.0 - 服务端版本
===========================================

【重要说明】
此mod是服务端版本，所有逻辑均在服务端执行，更安全可靠！

【功能介绍】
1. 玩家死亡后重生自动恢复所有装备
2. 完整保留装备状态（耐久度、弹夹、背包内物品等）
3. 记录每个玩家最近10次死亡的装备详情
4. 支持玩家中途下线后重新登录继续恢复
5. 防止装备重复（自动删除尸体）
6. 所有逻辑在服务端执行，防止客户端作弊

【支持的装备槽位】
- Body（上衣）、Legs（裤子）、Feet（鞋子）
- Back（背包）、Vest（背心）
- Headgear（帽子）、Mask（面罩）、Eyewear（眼镜）
- Gloves（手套）、Armband（臂章）
- Shoulder（肩部武器）、Melee（近战武器）
- Hips（腰部）
- sample_Pouch、Murasama_sheath、head（特殊插槽）

【工作流程】
1. 玩家死亡 → 服务端保存尸体引用和死亡记录
2. 玩家重生 → 服务端等待5秒（显示倒计时提示）
3. 清除默认装备 → 从尸体逐个转移装备
4. 每件装备间隔200ms → 确保客户端同步
5. 转移完成 → 删除空尸体

【文件保存位置】
死亡记录保存在：
data/Profiles/server/CYX_RespawnEquipment/DeathHistory.json

【注意事项】
1. 尸体引用有效期为1小时
2. 玩家中途下线后1小时内重新登录可继续恢复装备
3. 与 A6_SecureContainers mod 完全兼容
4. 必须在服务端安装，不需要客户端mod
5. 服务端代码无需密码保护（玩家无法访问服务端文件）

【安装方法】
1. 将编译后的 .pbo 文件放入服务器的 @ServerMod/Addons 目录
2. 在启动参数中添加 -servermod=@CYX_RespawnEquipment_Server
3. 重启服务器（无需任何配置文件）

【与客户端版本的区别】
- 客户端版本：已弃用，存在安全隐患
- 服务端版本：推荐使用，所有逻辑在服务端执行，更安全
