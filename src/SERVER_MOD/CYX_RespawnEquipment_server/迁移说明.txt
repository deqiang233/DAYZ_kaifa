【关键改动】
1. 移除所有 IsMultiplayer() 检查，改用 IsServer()
2. 所有函数添加服务端检查：if (!GetGame().IsServer()) return;
3. MessageImportant 仍可在服务端使用（会自动发送给对应玩家）
4. 移除密码验证（服务端文件玩家无法访问，无需密码保护）
5. 文件读写只在服务端执行

【如何使用】
1. 运行 run.ps1 脚本会自动打包服务端mod
2. 打包后的文件位置：build/@ServerMod/Addons/CYX_RespawnEquipment_server.pbo
3. 脚本会自动添加 -servermod 参数启动
4. 无需任何配置文件，开箱即用

【优势对比】
客户端版本 (旧)：
❌ 客户端可以修改代码作弊
❌ 需要玩家下载客户端mod
❌ 客户端和服务端都要检查
❌ 可能存在同步问题

服务端版本 (新)：
✅ 服务端统一管理，无法作弊
✅ 玩家无需下载任何mod
✅ 只在服务端执行，逻辑清晰
✅ 同步更可靠

【测试建议】

2. 进入游戏，准备好装备
3. 自杀测试
